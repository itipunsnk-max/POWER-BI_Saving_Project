# Infographic Backlog

ลำดับจัดทำตามค่าใช้จ่าย ความถี่ และความเสี่ยง

| Priority | Infographic | กลุ่มอาการ | จุดประสงค์ |
|---:|---|---|---|
| 1 | คัดกรองก่อนเปิดงานซ่อม | ทุกงาน | ลด dispatch ที่ไม่จำเป็น |
| 2 | น้ำมันไหลช้า/มือจ่ายไม่ตัด | มือจ่าย/แม่ปั๊ม | แยก Emergency กับ Routine |
| 3 | สายยาง/Swivel ตรวจภายนอก | สายยาง | พบ defect ก่อน breakdown |
| 4 | หน้าจอ/Preset/Error code | การแสดงผล | Remote triage ที่ปลอดภัย |
| 5 | เสียง/แรงสั่นผิดปกติ | มอเตอร์/สายพาน | Prevent repeat failure |
| 6 | ATG/Tank alarm | ถังใต้ดิน | Escalation ตามความเสี่ยง |
| 7 | ถ่ายรูปอะไรบ้าง | ทุกงาน | เพิ่ม First-time fix |
| 8 | Repair vs Replace | Bad actor asset | หยุดซ่อมสะสมไม่คุ้ม |
| 9 | PM/กฎหมาย Calendar | PM | ไม่พลาด due date |
| 10 | ปิดงานและบันทึก Root cause | ทุกงาน | ยกระดับ Data quality |

## Template เนื้อหาแต่ละใบ

1. อาการที่ผู้ใช้เห็น
2. ความรุนแรง: Critical / Urgent / Routine
3. สิ่งที่ทำได้
4. สิ่งที่ห้ามทำ
5. รูป/ข้อมูลที่ต้องแนบ
6. Decision: Self / Remote / Vendor / Statutory
7. Verification หลังทำ
8. QR ไป SOP เวอร์ชันล่าสุด
